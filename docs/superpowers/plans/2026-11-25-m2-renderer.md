# M2 Renderer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `turntable render model.glb --frames N` the ability to spin a real glTF model in headless Chromium and write the transparent PNG frames + `manifest.json` that the existing M1 player already knows how to show.

**Architecture:** A static, build-free three.js page (`renderer/index.html` + `renderer/render.js`, loaded via an import map from a pinned CDN, same zero-dependency spirit as `player/`) loads one `.glb`, auto-fits the camera to its bounding sphere, and exposes a small JS API that a Python driver (`turntable/stages/render.py`) calls once per angle through Playwright, decoding each returned PNG data URL to a file. A shared local static-file-server helper serves the renderer directory (and the model) for both the driver and a `conftest.py` refactor that removes the now-duplicated fixture-server code.

**Tech Stack:** three.js (ESM, via jsdelivr CDN, pinned version `0.187.0`), Playwright (Python sync API — becomes a runtime dependency, not just dev), Typer (existing CLI framework), pytest.

**Spec:** `docs/scope.md` (M2 milestone section, Architecture table row 3, Repository layout) and the conversation design recap below — no separate design doc file; the scope doc plus this plan are the spec of record for M2.

**Design recap (approved):** test fixture is Khronos' `Duck.glb` (already downloaded to `tests/fixtures/duck.glb`, with `tests/fixtures/duck.LICENSE.txt` — SCEA Shared Source License 1.0 — and `tests/fixtures/duck.NOTICE.txt` for attribution). Frames land in `frames/0001.png`..`NNNN.png` (1-indexed, 4-digit, matching the existing `tests/fixture_frames.py` convention) alongside a `manifest.json` with the same schema the player already reads (`version`, `title`, `width`, `height`, `frames[]`, `credits`). Default output directory is `player/` (already gitignored for exactly this generated-output purpose), default frame count 150, default size 1280×720.

## Global Constraints

- Python ≥3.10; ruff rules `E,F,I,B,UP`, line length 100 (`pyproject.toml`) must stay green.
- `$0`, fully local: the renderer calls no external API or Space.
- No build step for `renderer/` or `player/` — CDN `<script type="importmap">` / ES module imports only, exactly as `player/player.js` has zero dependencies.
- `manifest.json` schema must not diverge from what `player/player.js` already consumes: `{version, title, width, height, frames: string[], credits}`.
- Frame file naming: 1-indexed, 4-digit, e.g. `frames/0001.png` (matches `tests/fixture_frames.py`'s `frame_path`).
- Default frame count sits in the spec's "120–180 frames over 360°" range (default: 150, matching the scope doc's own example).
- CI has no GPU; Chromium's software WebGL (SwiftShader) must be sufficient — do not add a step that requires hardware acceleration.

## Review Focus

- `--frames 0` or a negative count: a reasonable person expects a clear error, not a crash or an infinite loop.
- A `model_path` that doesn't exist: a reasonable person expects a clear "file not found" before any browser even launches, not a deep Playwright stack trace.
- Re-running `render()` into an `out_dir` whose `frames/` already holds more files than the new frame count (e.g. a previous 150-frame run, now re-run with 5): the leftover files must not survive, or the folder will contain frames the new manifest doesn't list.
- A `model_path` that isn't valid glTF: the loader's error must surface as a clear Python exception with a bounded wait, not an indefinite hang.
- The frames must cover the full 360° turn without the last frame duplicating the first (an off-by-one that samples angle 0 twice wastes a frame and visibly stutters on loop).

```js
import * as THREE from "three";
import { GLTFLoader } from "three/addons/loaders/GLTFLoader.js";

const params = new URLSearchParams(location.search);
const width = Number(params.get("width")) || 1280;
const height = Number(params.get("height")) || 720;

const canvas = document.getElementById("stage");
const renderer = new THREE.WebGLRenderer({ canvas, alpha: true, antialias: true, preserveDrawingBuffer: true });
renderer.setPixelRatio(1);
renderer.setSize(width, height);

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(45, width / height, 0.01, 1000);
scene.add(new THREE.AmbientLight(0xffffff, 1.2));
const key = new THREE.DirectionalLight(0xffffff, 2.0);
key.position.set(1, 2, 3);
scene.add(key);

const turntable = new THREE.Group();
scene.add(turntable);

window.__turntableStatus = "loading";
window.__turntableError = null;

new GLTFLoader().load(
  "model.glb",
  (gltf) => {
    const box = new THREE.Box3().setFromObject(gltf.scene);
    const center = box.getCenter(new THREE.Vector3());
    const sphere = box.getBoundingSphere(new THREE.Sphere());
    gltf.scene.position.sub(center);
    turntable.add(gltf.scene);

    const fovRadians = (camera.fov * Math.PI) / 180;
    const distance = Math.max(sphere.radius / Math.sin(fovRadians / 2), 0.1);
    camera.position.set(0, 0, distance);
    camera.near = distance / 100;
    camera.far = distance * 100;
    camera.updateProjectionMatrix();
    camera.lookAt(0, 0, 0);

    window.__turntableStatus = "ready";
  },
  undefined,
  (error) => {
    window.__turntableError = String((error && error.message) || error);
    window.__turntableStatus = "error";
  },
);

window.renderAtAngle = function renderAtAngle(degrees) {
  turntable.rotation.y = (degrees * Math.PI) / 180;
  renderer.render(scene, camera);
  return canvas.toDataURL("image/png");
};
```
